# Local verification scope

The weather rebuild executed with Python 3.12.10 in isolated mode, networking disabled through a Python audit hook, and file access to D/E locations outside this package denied. All six variables across 28,127 city-days were exactly equal; the CSV SHA-256 was also identical to the main reference. Eight malformed-input/path-protection tests passed. See `weather_reconstruction_check.json`.

The initial isolated statistical launch stopped before analysis output creation because `packaging` was installed only in the Python user site and therefore hidden by `-I`. No package was installed, no dependency downloaded and no scientific output changed in response. `requirements.txt` now pins that dependency and the available runtime dependencies. The actual full statistical replay uses the installed Python environment with `-B`, three hash-confirmed local statistical modules, explicit package input and a dedicated D-drive output. `run_analysis_offline.py` disables Python-level network operations. The main scientific source was not edited for this replay.

Full statistical verification passed and is recorded in `analysis_reproduction_check.json`: all 271 scientific artifacts agree exactly (226 CSV, 40 NPZ, five JSON), including all missing-value locations. The owner-authored `FINAL_CODE_FREEZE.json` was hash-checked and checked against executed/frozen script identities; it is a source-only provenance record, not a file that a model run should regenerate. Execution times, script identities and the expanded passing test suite are explicitly distinguished from scientific values. No numerical tolerance was used in the independent comparison. The final run passed 15 tests, completed 20 models and 98 contrasts with 5,000 attempts per bootstrap scheme, and retained every unavailable all-city estimate.

The independent run's own saved-result audit passed 1,078 city contrasts, 294 scheme-by-contrast diagnostics and 1,470,000 saved replicate-contrast values; fixed-city synchronous draws rebuilt from sufficient statistics had maximum absolute error zero. The reference and reproduced output manifests were both verified. Reference weather and NO2 hashes stayed unchanged.

All three final figures and ten article tables were then regenerated with the release's portable CLI copies, using the independently reproduced analysis and byte-verified NO2 input. The original function ASTs are identical after the two documented table-path replacements. `presentation_reproduction_check.json` verifies all 27 artifacts: ten Markdown tables and six PNGs are byte-identical, nine vector files match except for their generation-date fields, and scientific ledger/metadata content is exact. The ledger's five execution-audit fields and the station report's timestamp and hash-validated input/output paths are explicitly recorded as runtime differences. Four presentation-layer tests passed. All three regenerated preview PNGs were visually inspected and showed no text clipping or overlap; this is distinct from the automated bounding-box checks performed by the generators.

These local runs do not verify a clean new virtual environment, offline wheel availability, another operating system or the author's final manuscript. Unpublished full text and submission files are deliberately outside the distributed code/data package, not unfinished release artifacts. Public-download and release-link verification is performed and recorded separately by the publishing owner.
